# File-Sorter
A simple Python script that automatically sorts files into folders by type. Built to save time on the repetitive file organizing that comes with data analytics work.

As a data analyst, I found myself constantly having to manually sort through downloads and project folders full of CSVs, PDFs, SQL files, and text documents. This script automates that. It scans a folder and moves each file into the correct subfolder based on its extension, so I don't have to do it by hand every time.
